Featured project: Campus Feedback Sentiment Analyzer

AI-based application development · Mini Project 1

Problem. Colleges receive hundreds of feedback comments each semester, and reading them manually is slow, so recurring problems get missed.

Solution. A web app that reads feedback, labels it positive or negative with a confidence score, detects the topic (Wi-Fi, Food, Faculty, Hostel and more), and shows a dashboard of satisfaction by topic.

Highlights
  • Naive Bayes model trained in the browser
  • Handles mixed comments like “good teachers but slow wifi”
  • Understands negation (“not good”)
  • Learns from user corrections
My process
Ideated the problem with Gemini
Built the dataset and baseline model
Tested, found errors, improved the model
Added dashboard, history and learning
Published and documented
